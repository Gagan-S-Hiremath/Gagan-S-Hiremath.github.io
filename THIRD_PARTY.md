# Third-party materials and originality

The portfolio uses browser-native HTML, CSS and JavaScript with dependency-free Node.js build scripts. No source code, case-study text, branding or imagery from the researched portfolio examples, promptfoo, Phoenix, Ragas or LangSmith is copied into this implementation.

DM Sans and Manrope are loaded from Google Fonts with system fallbacks. The repository does not redistribute font binaries. Font rights remain with their respective authors.

The photograph and résumé were supplied by the portfolio owner and are excluded from the source-code licence. LinkedIn, Power BI, Azure, LangGraph and other product names identify relevant platforms; no endorsement is implied.

The separate working prototype retains its existing pinned dependency list, source identifiers, capability catalogue and library licence obligations. The portfolio publishes a genuine empty-state interface screenshot and summarised verification, not the prototype's credentials, real prospect records, database or confidential files.
